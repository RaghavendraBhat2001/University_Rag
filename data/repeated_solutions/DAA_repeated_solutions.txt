Question: Explain different asymptotic notations in detail.
------------------------------------------------------------
Model Solution (calibrated for full marks):
### Asymptotic Notations in Algorithm Analysis (6 Marks)

Asymptotic analysis evaluates algorithmic time and space complexity as input size $n \to \infty$, abstracting hardware variations.

1. **Big-O Notation ($O$):**
   - Upper bound (Worst-Case rate of growth).
   - $f(n) = O(g(n)) \iff \exists c > 0, n_0 \ge 1$ such that $0 \le f(n) \le c \cdot g(n) \; \forall n \ge n_0$.
2. **Big-Omega Notation ($\Omega$):**
   - Lower bound (Best-Case guarantee).
   - $f(n) = \Omega(g(n)) \iff \exists c > 0, n_0 \ge 1$ such that $0 \le c \cdot g(n) \le f(n) \; \forall n \ge n_0$.
3. **Big-Theta Notation ($\Theta$):**
   - Asymptotically tight bound.
   - $f(n) = \Theta(g(n)) \iff c_1 g(n) \le f(n) \le c_2 g(n) \; \forall n \ge n_0$.
4. **Little-o ($o$) and Little-omega ($\omega$):**
   - Strictly upper ($f(n) < c \cdot g(n)$) and strictly lower bounds where ratio limits converge to 0 and $\infty$ respectively.

QUESTION #2 [6 MARKS] (Exam Sittings: 2025, 2022)
Question: Present Brute-force based algorithm to perform pattern matching and investigate its efficiency.
------------------------------------------------------------
Model Solution (calibrated for full marks):
### Brute-Force String Pattern Matching Algorithm & Efficiency (6 Marks)

Given Text $T[0..n-1]$ and Pattern $P[0..m-1]$ ($m \le n$):

#### Algorithm:
```text
Algorithm BruteForceStringMatch(T[0..n-1], P[0..m-1])
For i := 0 to n - m do:
    j := 0
    While j < m and P[j] = T[i + j] do:
        j := j + 1
    If j = m then:
        Return i  // Match found at index i
Return -1         // No match found
```

#### Efficiency Analysis:
- **Best Case:** $O(m)$ when pattern matches at the very beginning of text.
- **Worst Case:** $O(m(n - m + 1)) \approx O(m \cdot n)$ when characters match repeatedly until the last pattern character (e.g., $T = \text{"AAAAAAA"}$, $P = \text{"AAAAB"}$).
- **Space Complexity:** $O(1)$ auxiliary space.
