----------------------------------------------------------------------

SET THEORY

📘 As per your notes, Set Theory is a fundamental mathematical framework that allows the construction and analysis of sets, which are collections of objects. Two basic operations in Set Theory are Intersection and Union.

- Intersection (∩) of two sets A and B, denoted as A ∩ B, is the set that contains all elements common to both A and B. In other words, it is the set of elements that belong to both A and B.

- Union (∪) of two sets A and B, denoted as A ∪ B, is the set that contains all elements from A and B. In other words, it is the set of elements that belong to A or B (or both).

Question: Prove that “null set is a subset of every set”.
----------------------------------------------------------------------
Model Answer:
SET THEORY

📘 Set Theory: A mathematical framework for defining, manipulating, and reasoning about collections of objects, called sets. It provides a systematic way to describe and analyze various mathematical structures.

💡 Think of a set as a box containing items. A subset is a smaller box that can fit inside the main box, containing some (but not necessarily all) of the items. The null set (or empty set) is a special set that contains no items at all.

- Subset: A set A is a subset of another set B if every element in A is also an element of B. In other words, all members of A are also members of B.
- Null Set: A set with no elements is called the null set or empty set. It is denoted by the symbol {∅}.

Key differences:
- A subset always contains elements that are also in the original set, while the null set contains no elements at all.
- A subset can have multiple elements, while the null set has none.

QUESTION #7  (5 Marks)  -  asked in 3 exam sittings [2025, 2022, 2021]
Question: The matrix of a relation on the set A = {1, 2, 3} is given by M_R = [1 0 0 / 0 1 1 / 0 1 1]. Show that R is an equivalence relation.
----------------------------------------------------------------------
Model Answer:
RELATION

📘 As per your notes, a Relation is a set of ordered pairs that connect elements from one or more sets. In the context, a relation on a set A to itself (a relation on A) is a subset of A x A, where A x A represents the Cartesian product of A with itself.

Equivalence Relations are a specific type of relation that have three properties: reflexive, symmetric, and transitive.

- Reflexive: For every element a in the set A, (a, a) belongs to the relation. In other words, every element is related to itself.
- Symmetric: If (a, b) is in the relation, then (b, a) is also in the relation. This means that if element a is related to element b, then b is related to a.
- Transitive: If (a, b) and (b, c) are in the relation, then (a, c) is also in the relation. This means that if a is related to b and b is related to c, then a is related to c.

Equivalence relations are important throughout mathematics and computer science because they allow us to group similar objects together. For example, in set theory, we can define an equivalence relation on the integers that groups together all numbers with the same remainder when divided by a certain number.

💡 Simple way to understand it: Think of an equivalence relation as a way to group similar objects together. Imagine you have a box of marbles, and you want to group them by color. You would create a relation where two marbles are related if they are the same color. This relation is reflexive (every marble is related to itself), symmetric (if two marbles are the same color, they are equally related), and transitive (if marble A is the same color as marble B, and marble B is the same color as marble C, then marble A is the same color as marble C).

QUESTION #8  (5 Marks)  -  asked in 3 exam sittings [2025, 2023, 2021]
Question: State and prove the Bayes’ theorem.
----------------------------------------------------------------------
Model Answer:
BAYES' THEOREM

📘 As per your notes, Bayes' theorem is a mathematical formula used to calculate conditional probabilities in various disciplines. It helps solve problems where the goal is to update the probability of a hypothesis based on new evidence. The theorem is expressed as follows:

p(F∣E) = p(E∣F) * p(F) / p(E)

where:
- p(F∣E) is the probability of hypothesis F given evidence E
- p(E∣F) is the probability of evidence E given hypothesis F
- p(F) is the prior probability of hypothesis F
- p(E) is the total probability of evidence E (sum of probabilities of all possible hypotheses that could generate the evidence)

The theorem can also be rewritten as:

p(E∣F) * p(F) = p(E∣F) * p(F) + p(E∣F') * p(F')

where F' represents the complement of F (all possible hypotheses except F).

💡 A simple way to understand Bayes' theorem is by imagining a coin toss. Suppose you have a biased coin that lands on heads 70% of the time and tails 30% of the time. If you toss the coin once and it lands on heads, Bayes' theorem helps you update your belief about the coin's bias based on the new evidence (the toss result). The theorem calculates the updated probability of the coin being biased towards heads (F) given the evidence (the toss result).

QUESTION #10  (5 Marks)  -  asked in 3 exam sittings [2025, 2023, 2022]
Question: State and prove Hand Shaking theorem.
----------------------------------------------------------------------
Model Answer:
HAND SHAKING THEOREM

📘 The Hand Shaking Theorem states that in an undirected graph, the sum of the degrees of all vertices is equal to twice the number of edges. This theorem applies even if multiple edges and loops are present.

The proof is based on the handshaking analogy: each edge connects two vertices, so each edge contributes two to the sum of the degrees of the vertices. Therefore, the total number of edges (m) is half of the sum of the degrees of the vertices. Since each edge is counted twice (once for each vertex it connects), the sum of the degrees equals twice the number of edges, i.e., 2m.

💡 Imagine a party where each person shakes hands with others. The total number of handshakes is equal to the sum of the number of handshakes each person makes (their degree) multiplied by the total number of people (twice the number of edges). This is the Hand Shaking Theorem in a social setting.

QUESTION #11  (3 Marks)  -  asked in 2 exam sittings [2023, 2021]
Question: Show that p ∨ (q ∧ r) = (p ∨ q) ∧ (p ∨ r).
----------------------------------------------------------------------
Model Answer:
P ∨ (Q ∧ R) = (P ∨ Q) ∧ (P ∨ R)

📘 As per your notes, the Distributive Law in Boolean Algebra states that the operation of 'OR' (∨) distributes over the operation of 'AND' (∧). In simpler terms, this means that for any elements p, q, and r in a Boolean algebra, p ∨ (q ∧ r) is equivalent to (p ∨ q) ∧ (p ∨ r).

💡 Think of a Venn diagram with three overlapping circles representing p, q, and r. According to the Distributive Law, the total area covered by p OR (q AND r) is the same as the area covered by (p OR q) AND (p OR r). This is because the area covered by p OR q is the union of the areas covered by p and q, and the area covered by p OR r is also the union of the areas covered by p and r. The intersection of p with both q AND r is included in both the left and right sides of the equation, ensuring the equality.
