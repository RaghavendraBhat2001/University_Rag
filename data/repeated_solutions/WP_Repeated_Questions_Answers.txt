QUESTION #1  (6 Marks)  -  asked in 2 exam sittings [2024, 2023]
Question: Discuss the difference between GET and POST methods in AJAX Request.
----------------------------------------------------------------------
Model Answer:
GET VS POST METHODS IN AJAX REQUEST

📘 As per your notes, the GET and POST methods are two ways to send data from a client (usually a web browser) to a server in an AJAX (Asynchronous JavaScript and XML) request.

- GET method: This method appends the data to the URL as query parameters. The data is visible in the URL and can be bookmarked or shared. It has a limit on the amount of data that can be sent (usually around 1000 characters). GET requests are often used for retrieving data from the server.

- POST method: This method sends the data as the body of the HTTP request. The data is not visible in the URL and cannot be bookmarked or shared easily. It has no limit on the amount of data that can be sent. POST requests are often used for sending data to the server, such as submitting a form.

💡 Simple way to understand it:
Think of a letter you're sending through the mail. A GET request is like sending a postcard where the message is written on the outside for everyone to see. A POST request is like sending a sealed envelope where the message is hidden inside.

QUESTION #2  (5 Marks)  -  asked in 2 exam sittings [2025, 2023]
Question: What is Local storage and how is it useful ?
----------------------------------------------------------------------
Model Answer:
LOCAL STORAGE

📘 Local storage refers to the storage space on a workstation that is distinct for each workstation in a network. It contains essential system programs for autonomous operation and better performance, temporary files, and files that the workstation owner wants to store privately.

💡 Local storage is like a personal locker in a shared gym. Each gym member (workstation) has their own locker (local storage) to store their personal items (system programs, temporary files, and private files) for their exclusive use, ensuring better performance and privacy.

In the context of the Virtue network, local storage serves as the root file system from which the shared name space descends. This local storage is necessary for each workstation to operate autonomously and efficiently, as well as to maintain privacy by storing certain files locally. Additionally, servers can improve efficiency by storing requested files in a cache in memory and through multithreading or multiprocessing.

Key differences:
- Local storage is personal to each workstation, while the shared name space is accessible by all workstations.
- Local storage is used for essential system programs, temporary files, and private files, while the shared name space is used for shared resources like web pages.
- Local storage is stored on the local disk of each workstation, while the shared name space is managed collectively by the servers.
